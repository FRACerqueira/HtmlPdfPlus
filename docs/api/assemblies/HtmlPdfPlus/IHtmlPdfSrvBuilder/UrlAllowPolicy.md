### IHtmlPdfSrvBuilder.UrlAllowPolicy method
</br>


#### Overrides the policy used to decide whether a Url request is allowed to be navigated to. The default policy allows only http/https and denies private, loopback and link-local address ranges - which also covers common cloud metadata endpoints such as `169.254.169.254` - closing the SSRF vector inherent to navigating to an arbitrary caller-supplied URL.
