### HtmlPdfEndpointExtensions.MapHtmlPdfEndpoints&lt;TIn,TOut&gt; method (3 of 3)

#### Maps the HTML to PDF conversion endpoint for an `IHtmlPdfServer<TIn, TOut>` service. A successful `byte[]` output is served as the raw PDF (`application/pdf`); any other *TOut* is served as JSON. A failed conversion is served as the structured ErrorInfo contract, with the HTTP status mapped from its ErrorCode (see ErrorCode)).
